# 신규 선수 전투 동작 및 카드별 시연 검수

## 변경 범위

- 아틀라스·세라프·링스·템페스트·오닉스에 12개 완성 전신 포즈씩 추가. 내장 이미지 생성 도구에 각 선수의 보통 상태를 참고 이미지로 제공했고, 1086×1448 투명 PNG 원본을 픽셀 편집 없이 사용했다. [정확한 프롬프트](classic-actions/newcomer-prompts.json).
- 기존 다섯 명과 같은 전신 표면 보간, 상대 접촉, 동작 종료 복귀와 GPU 사용 불가 시 완성 일러스트 대체 경로를 사용한다.
- 선수 메뉴에서 모든 60종 카드를 선수별로 시연한다. 무작위 상대는 선택한 선수를 제외하며 재시연마다 다시 뽑는다. 같은 상대가 연속으로 나올 수 있다.
- 원본/SD 전환, 카드 검색과 기술 분류, 재시연과 중지, 선수 목록 복귀를 제공한다. 시연에서 사용하는 임시 경기에는 현재 런과 브라우저 저장소가 전달되지 않는다.
- 타격은 흰색 중심과 금색 불꽃, 던지기는 매트 접촉의 금색 섬광·먼지·파편, 관절기는 작은 압박 표시, 완전 방어는 작은 방어 접촉으로 구분한다. 실제 피해가 없는 유틸리티에는 타격 섬광을 만들지 않는다.

## 검증

- 전체 Node 테스트 355개 통과. 열 명 × 60카드의 임시 시연, 실제 선수 패시브, 자기 자신을 제외한 상대 아홉 명, 원본/SD 시연의 연속 시계, 기존 엔진과 저장 호환을 포함한다.
- 열 명 × 12포즈의 분리된 알파 실루엣을 측정하고 인접 포즈가 크롭에 들어오지 않는지 검사했다. [알파 측정 결과](classic-actions/alpha-qa.json). 추가 60포즈의 14개 기준점은 포즈별 해부학적 가이드에서 등록한 뒤 해당 실루엣 내부로 보정했다. 재현: `tools/register-newcomer-actions.py`.
- `/slay/` 베이스 경로의 Vite 배포 빌드 통과.
- 로컬 브라우저에서 아틀라스 파워밤, 세라프 드롭킥, 링스 레그록, 템페스트 수플렉스, 오닉스 크로스페이스의 선수별 동작과 무작위 상대를 확인했다. 신규 선수의 전신 보간 표면이 준비된 상태에서 표시됨을 확인했다.
- SD 모드의 오닉스 리스트록에서 카드 기술 연출 다음 실제 오닉스와 무작위 상대가 표시되는 것을 확인했다. 검색 결과, 시연 중지와 선수 목록 복귀도 확인했다.
- 393×852 세로 화면과 844×390 가로 화면에서 가로 넘침 없이 사용 가능함을 확인했다. 세로 화면의 동작 단계·기술 제목 겹침을 수정했고, 짧은 가로 화면에서는 시연 높이를 줄여 화면 안에 공방과 결과를 함께 배치했다.
- 중간 동작 검수에는 개발 전용 `qaFluidFrame=0.5`를 사용했다. 이 옵션은 배포 빌드에서 비활성화된다. 실제 재생도 별도로 확인했으며, 새 선수에 대해 FPS 성능 측정치를 주장하지 않는다.

## 한계

동작은 12개 완성 포즈를 카드 종류에 따라 보간한다. 60개 카드마다 별도의 전신 원화를 그린 방식은 아니다. GPU나 에셋 준비 상태에 따라 완성 포즈 대체 화면이 표시될 수 있으며, 모션 감소·간결 설정은 동작을 줄인다.
