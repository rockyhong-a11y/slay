# 선수 확장과 기술 연출 검수 — 2026-10-05

## 완성 범위

- 카드 50종에 개별 효과 프로필을 연결했다. 타격은 방향 잔상·접촉 폭발, 그래플링은 잡는 손·들기/회전·매트 파동, 서브미션은 관절 타깃·조임·유한 압박 맥동으로 구분한다. 방어·운영·악몽도 별도 효과를 사용한다.
- 실제 카드 그림을 확인해 접촉 좌표를 지정했다. 효과는 완성 그림과 같은 카메라 프레임에서 움직이며, 세로 크롭·레터박싱에 맞춰 좌표를 보정한다. ResizeObserver는 해제 시 정리한다.
- ATLAS, SERAPH, LYNX, TEMPEST, ONYX를 추가해 선수 10명이다. 다섯 선수의 체형은 기존 카툰 운동선수 스타일을 따르며 각각 고유 패시브와 11장 시작 덱을 사용한다.
- 신규 전신 이미지 30장을 추가해 전체 60장이다. 모든 상태는 완성된 한 장의 투명 이미지이며 얼굴 확대는 같은 그림의 크롭이다. 신규 이미지 30개는 서로 다른 1000×1500 RGBA WebP이다.

## 자동 검사

- `npm test`: **137/137 통과**. 10명 전원의 8구간 완주, 50개 카드 기본·강화 효과, 신규 패시브의 턴별 한도·저장 복원·무효 입력, 기존 덱 보존, 120개 선수·시드·경로 정책 조합을 포함한다.
- 타격·던지기·서브미션의 유한 타임라인, 실제 피해와 가드 결과, 공격 없는 지원 효과, 간결·모션 감소 처리와 그림 좌표 투영을 검사했다.
- `BASE_PATH=/slay/ npm run build`: 성공. 배포 JS에 `qaActor`, `qaHand`, `qaJourney`가 포함되지 않는 것을 확인했다.
- Blender 갤러리는 60개의 완성 이미지 평면을 동일 배율로 비교한다. 원본 텍스처 바이트·전체 UV·화면 내 배치 등 13개 검사가 모두 통과했다. 갤러리는 2D 검수 장면이다.

## 실제 브라우저

Codex In-app Browser에서 DEV 전용 격리 전투를 사용했다. 일반 저장 슬롯에 QA 전투를 기록하지 않는다.

- 선수 목록 10명, 신규 필터 5명, 다섯 선수의 실제 새 런과 시작 손패를 확인했다.
- 신규 5명 × 6상태를 UI로 선택했다. 전신과 얼굴 확대 모두 정확한 상태 그림을 로드했다. 세라프 지침·그로기 얼굴 크롭을 수정하고 다시 확인했다.
- 393×852, 844×390, 320×720에서 신규 선수와 상대, 10장 손패 및 사용 버튼이 화면 안에 있다. 문서 크기는 화면 크기와 같고 문서 스크롤은 0이다.
- 320×720에서 손패를 1번 위치부터 9번까지 드래그하면 9번만 16px 상승·선택되며 손패 10장을 유지한다. 파워밤 더블탭은 한 번만 시전되어 손패 9장으로 줄었다.
- 엘보·파워밤·암바를 실제 사용하고 연속 프레임의 opacity/transform 변화를 기록했다. 각 계열의 효과가 서로 다르며, 배경은 blur(26px)로 흐려진다. 효과와 기술 그림은 동일 카메라 프레임에 포함된다.
- 세로 암바는 cover 및 60% 62% 초점으로 표시되며 효과가 관절 위치를 따라간다.
- 간결 모드는 650ms, hitstop 0, 효과 레이어 0의 정적 결과 표시로 동작한다. 검수 후 전체 연출 설정을 복원했다.
- 최종 검수 탭의 브라우저 콘솔 오류 0개.

실제 iOS Safari 기기 검수나 OS 모션 감소 설정 변경은 수행하지 않았다. 모션 감소는 코드와 자동 테스트로 검증했다.
